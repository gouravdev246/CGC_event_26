RAG-as-a-Service Platform API

Welcome to the KnowAPI developer documentation. Our platform provides a ready-made, multi-tenant Retrieval-Augmented Generation (RAG) backend. Organizations, colleges, and developers can upload their documents (PDFs, knowledge bases), receive an authenticated endpoint with an API key, and instantly power custom AI chatbots.

Default Base URL
http://localhost:5000/api
● Server Active
⚡ How the End-to-End RAG Flow Works
1
Upload Documents
Upload a PDF through /api/files/upload. The system parses and chunks the document into vector embeddings.
2
Vector Storage
Embeddings are indexed in Pinecone tagged with your userId as the metadata source for complete tenant isolation.
3
Instant API Endpoint
Receive an API Key and an endpoint: /api/{userid}/{apikey}/chat. Temporary upload files are cleaned up from disk.
4
Chatbot Querying
Send questions from your frontend chatbot. Grounded answers are generated using semantic search and our LLM.

🔐 Authentication Guide

The platform utilizes two distinct authentication mechanisms depending on the route type:

1. User JWT Token (Admin / Dashboard)

Used for authenticated user endpoints like document uploading (/api/files/upload) and generating API keys (/api/keys/generate). 

Authorization: Bearer <jwt_token>

2. Public RAG API Key (Chatbots)

Used by client chatbots, apps, and websites querying the RAG knowledge base. Can be passed directly in the URL path, via the x-api-key header, or Bearer token. 

/api/:userid/:apikey/chat

2. Knowledge Ingestion (File Upload)

POST /api/files/upload
Bearer Token / Optional

Upload a PDF document. The server automatically:
1. Loads and splits the document into text chunks.
2. Generates Cohere vector embeddings and indexes them in Pinecone tagged with your userId.
3. Deletes the physical file from the server's uploads/ folder.
4. Returns your persistent API key and ready-to-use Chatbot API endpoints.

ParameterTypeLocationRequirementDescription
fileFile (binary)FormDataRequiredThe PDF document to ingest into your RAG knowledge base.
userIdstringBody / TokenOptionalIf not using Bearer JWT, supply custom user ID in form body.

4. Public RAG Chatbot Service Endpoints

These endpoints are designed for third-party websites, apps, and chatbot UIs. They authenticate via your generated API Key and execute vector similarity search filtered strictly to your organization's documents.

POST /api/:userid/:apikey/chat
API Key in Path

Direct turnkey endpoint. Send queries directly with your user ID and API key in the URL path. Perfect for no-code tools, simple widget embeds, and quick integrations.

ParameterTypeLocationRequirementDescription
:useridstringPathRequiredThe organization/user ID that owns the uploaded knowledge base.
:apikeystringPathRequiredThe valid API key matching this user account.
messagestringBody (JSON)RequiredThe user query / question to answer. Also accepts query.
historyarrayBody (JSON)OptionalConversation history: [{"role":"user","content":"..."},{"role":"assistant","content":"..."}]
knumberBody (JSON)OptionalNumber of context chunks to retrieve (default: 4, max: 10).

🚀 Client Quickstart Code Examples

Copy and paste these snippets to integrate your RAG chatbot into any frontend website, React component, or Python backend.

curl -X POST "http://localhost:5000/api/YOUR_USER_ID/YOUR_API_KEY/chat" \ -H "Content-Type: application/json" \ -d '{ "message": "What is the fee structure for BCA?", "k": 4 }'
async function askKnowledgeBot(question) { const userId = "YOUR_USER_ID"; const apiKey = "YOUR_API_KEY"; const response = await fetch(`http://localhost:5000/api/${userId}/${apiKey}/chat`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ message: question }) }); const data = await response.json(); console.log("Bot Answer:", data.answer); return data; } // Example usage askKnowledgeBot("What scholarships are offered?");
import requests USER_ID = "YOUR_USER_ID" API_KEY = "YOUR_API_KEY" URL = f"http://localhost:5000/api/{USER_ID}/{API_KEY}/chat" payload = { "message": "When is the deadline for autumn enrollment?" } response = requests.post(URL, json=payload) data = response.json() print("Status:", data.get("success")) print("Answer:", data.get("answer"))
